# EasyRight v0.1.0 发布说明

[English Release](https://github.com/LightDevCoder/EasyRight/releases/tag/v0.1.0) | **中文发布说明**

欢迎体验 **EasyRight**（`v0.1.0`）首个公开发布版本 —— 一款轻量极速、零外部依赖、采用 Swift / SwiftUI / AppKit 纯原生构建的 macOS 访达（Finder）右键菜单增强助手。

---

## 核心亮点

- **30+ 原生右键动作**：
  - **新建文件**：支持快速新建 `.txt`、`.md`、Word `.docx`、Excel `.xlsx`、PowerPoint `.pptx`、`.json`、`.csv`、`.html`、`.pdf`。
  - **开发者专属**：快速在终端（Terminal / iTerm2 / Warp）中打开当前目录、在代码编辑器（VS Code / Cursor / Sublime Text）中打开工程、Git 相对路径与 Shell 安全路径拷贝。
  - **文件流转与实用工具**：安全剪切/粘贴、POSIX 路径拷贝、文件名拷贝、文件哈希校验（MD5 / SHA256）、剪贴板文本转二维码、图片快速格式转码及系统隐藏文件一键切换。
- **自由编排动作画布**：
  - 现代亚克力设计风格的菜单工作台，支持动作的自由拖拽排序、灵活分组及插入原生分隔线。
  - 右侧配备 60fps 1:1 像素级拟真原生菜单实时渲染预览，所见即所得。
- **自定义外部应用扩展**：
  - 自由添加系统已安装的任意应用程序（如 Keka 压缩解压、Typora、IINA、Sublime Merge 等）至右键菜单。
  - 支持按文件、目录、特定扩展名等精细化过滤规则触发。
- **双语界面与即时热切换**：
  - 偏好设置中自由切换中文与英文界面，全局组件与动作标题无缝即时响应，无需重启应用。
- **预设方案一键直达**：
  - 点击左上角标题或在偏好设置中一键切换极简日常（`Lite`）、开发者特供（`Dev`）与全能全景（`Max`）方案。
  - 标题栏尾缀微徽标根据当前配置动态联动响应（手动调整后精准标记为 `User`）。
- **全新浅色应用图标与 DMG 卷标图标**：
  - 配备全新浅色高保真应用图标（带平滑圆角透明光影）。
  - DMG 安装镜像内嵌自定义卷标图标，带来丝滑的原生开箱体验。
- **极速性能与纯净隐私**：
  - 采用解耦双进程架构（`FIFinderSync` 扩展 + 宿主应用），右键菜单毫秒级即时弹出，绝不阻塞 Finder。
  - 0 外部依赖、0 广告、0 遥测、0 后台静默网络轮询。
- **Universal 2 架构支持**：
  - 原生支持 Apple Silicon（M1~M4）与 Intel 芯片 Mac，兼容 macOS 13.0 (Ventura) 及更高版本。

## 快速上手

1. 前往 [Release 下载页面](https://github.com/LightDevCoder/EasyRight/releases/tag/v0.1.0) 下载 `EasyRight-v0.1.0-macOS-Universal.dmg`。
2. 双击打开镜像，将 `EasyRight.app` 拖入 **Applications**（应用程序）文件夹。
3. 从启动台或菜单栏打开 EasyRight，首次启动根据引导在「系统设置 > 扩展」中勾选启用 EasyRight 访达扩展即可。

### Homebrew 安装（可选）

```bash
brew install --cask easyright
```
