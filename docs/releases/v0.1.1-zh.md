# EasyRight v0.1.1 发布说明

[English Release](https://github.com/LightDevCoder/EasyRight/releases/tag/v0.1.1) | **中文发布说明**

**EasyRight** `v0.1.1` 正式发布！本版本重点带来了**无感配置双重持久化与重装自愈系统**，彻底解决了卸载重装或系统清理工具抹除沙盒导致用户配置丢失的问题；同时全面适配了最新的 **macOS 27 (Golden Gate)** 与 **Swift 6** 构建工具链。

---

## v0.1.1 核心更新与亮点

### 1. 🛡️ 无感配置双重持久化与灾难自动恢复 (Seamless Config Persistence)
- **实时双写镜像备份**：
  所有动作开关（`config.json`）、菜单排布画布（`action_config.json`）与自定义 App 快捷动作（`custom_app_actions.json`）在保存至扩展沙盒容器的同时，**毫秒级原子镜像同步**至宿主专属安全持久化目录：`~/Library/Application Support/EasyRight/ConfigBackup/`。
- **重装启动零操作自愈 (Zero-Touch Recovery)**：
  当用户使用 AppCleaner / CleanMyMac 卸载重装、覆盖安装或清理系统垃圾导致扩展沙盒容器被清空时，EasyRight 启动最前置阶段自动检测并**毫秒级自愈还原**所有历史配置，并热重载访达扩展。你的自定义菜单项、排序与第三方应用映射 100% 完好如初。
- **老用户平滑升级补录**：
  现有老用户启动后系统自动探测并将当前已有配置生成初始备份，无需任何手动迁移。
- **卸载脚本分级保护**：
  优化 `uninstall.sh` 脚本，默认卸载时完整保留用户的持久化配置备份；仅在显式传入 `--purge` 时才做物理抹除。

### 2. 🍏 macOS 27 (Golden Gate) & Swift 6 构建全面适配
- **CLT 独立环境智能编译适配**：
  针对 macOS 27 SDK 将 SwiftUI `@State` 重构为 Attached Macro 但命令行工具未附带宏插件的问题，`build.sh` 引入了智能 SDK 探测与回退机制，确保在纯 CLT 命令行与 CI 环境下均能一键稳定编译。
- **架构构建指令增强**：
  构建脚本新增 `TARGET_ARCHS` 支持（支持 `universal` 或纯 `arm64`），适应 macOS 27 对 Apple Silicon 的专属优化。
- **Swift 6 严格并发与编译器规范**：
  消除所有异步闭包捕获与 Combine 模块导入警告，全面通过 Swift 6 严格模式校验。

## EasyRight 基础特性一览

- **30+ 原生右键动作**：新建多类型文件（Office/Markdown/代码）、终端直达（Terminal/iTerm2/Warp）、编辑器唤起（VS Code/Cursor/Sublime Text）、Git/POSIX 路径一键复制、哈希计算、Base64 转码与隐藏文件切换。
- **自由编排动作画布**：亚克力半透明工作台，可视化拖拽排序、自由分组，右侧配备 60fps 实时 1:1 原生菜单拟真预览。
- **自定义外部应用快捷方式**：自由添加系统任意已安装应用（如 Keka、Typora、IINA 等）作为右键菜单项，支持精细化文件扩展名过滤。
- **极速性能与纯净隐私**：解耦双进程架构（`FIFinderSync` 插件毫秒级弹出），0 外部依赖、0 网络轮询、0 广告与遥测。
- **Universal 2 胖二进制**：原生支持 Apple Silicon（M1~M4）与 Intel 芯片 Mac，兼容 macOS 13.0+。

## 快速上手与下载

1. 在 GitHub Release 资产中下载 `EasyRight-v0.1.1-macOS-Universal.dmg`。
2. 双击打开磁盘映像，将 `EasyRight.app` 拖入 **Applications**（应用程序）文件夹。
3. 从启动台或菜单栏打开 EasyRight，根据引导在「系统设置 > 扩展」中勾选启用 EasyRight 访达扩展。

### Homebrew 安装（可选）

```bash
brew install --cask easyright
```
